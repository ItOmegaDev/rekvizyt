# Реквізити

Внутрішній сервіс для ФОП: генерація пари документів — **Рахунок на оплату** та
**Акт прийому-передачі наданих послуг** — у форматі А4, українською мовою, з
сумою прописом. Дані зберігаються на вашому сервері (SQLite).

## Можливості

- Два варіанти «Моїх реквізитів» (різні банки) — вибираються при створенні документа.
- Договори замовників: вибір договору автоматично підставляє реквізити замовника
  і тип послуги в акт.
- Ручне введення ціни та кількості, автопідсумок і сума словами.
- Одна дата для рахунку й акта; номер `NN-MM` використовується обома документами.
- Друк і збереження в PDF через діалог браузера (A4, Times New Roman).
- Історичні документи зберігають знімок реквізитів — зміни довідників не
  впливають на вже створені документи.
- Вхід через Google OAuth зі списком дозволених email; у розробці — локальний
  вхід (прапорець `DEV_LOGIN`).

## Стек

- Monorepo (npm workspaces): `shared` (типи, схеми, гроші/дати), `server` (Express 4 +
  TypeScript, SQLite через `node:sqlite`), `client` (React 19 + Vite + TypeScript).
- Валідація: zod на сервері й клієнті.
- Безпека: helmet (CSP), CSRF за Origin, rate-limit, httpOnly cookie, Google ID-token
  верифікація.

## Швидкий старт

```bash
cp .env.example .env
# відредагуйте .env: SESSION_SECRET (>=32 символи), за потреби GOOGLE_CLIENT_ID
npm install
npm run dev
```

Відкрийте http://localhost:5173 — у dev-режимі (`DEV_LOGIN=1`) на сторінці входу
з’явиться кнопка «Увійти як локальний адміністратор».

## Скрипти

| Команда | Що робить |
|---|---|
| `npm run dev` | сервер (4000) + Vite (5173) одночасно |
| `npm run build` | зібрати сервер і клієнт |
| `npm run typecheck` | перевірка типів усіх пакетів |
| `npm test` | unit + API тести (node:test) |
| `npm run smoke` | build + запуск сервера + /api/health |

## Структура

```
shared/src/   — типи, zod-схеми, гроші словами, дати, побудова документів
server/src/   — config, db (SQLite), репозиторії, маршрути, seed, app
client/src/   — сторінки, компоненти, стилі А4
```

## Друк і PDF

Відкрийте документ → «Друк / PDF». У діалозі друку виберіть «Зберегти як PDF»,
розмір паперу A4, поля за замовчуванням (макет вже має власні поля).
Друкується лише обрана вкладка (Рахунок / Акт / Обидва).

## Тести

```bash
npm test
```

Покривають: гроші словами й форматування, дати, IBAN, вступні фрази, а також
повний API-сценарій (вхід, довідники, створення/редагування/повторення/видалення
документа, валідація, CSRF).
